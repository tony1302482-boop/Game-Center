Game Center – Version 0.8.0

GitHub-Repository:
https://github.com/tony1302482-boop/Game-Center

UPDATE:
Im Menü „Über Game Center“ befindet sich die Schaltfläche „Update“.
Sie fragt die neueste GitHub-Veröffentlichung ab. Wenn eine neuere Version
mit angehängter EXE-Datei vorhanden ist, kann sie heruntergeladen und
installiert werden.

Ein GitHub-Release muss einen Versions-Tag (z. B. v0.8.1) und die EXE
„Game Center.exe“ als Release-Asset enthalten.

BUILD:
Auf Windows EXE_erstellen.bat ausführen. Die EXE befindet sich danach in dist.
