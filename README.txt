Game Center – Version 0.7.0

GitHub-Repository:
https://github.com/tony1302482-boop/Game-Center

UPDATE-VERFAHREN:
- Game Center prüft beim Start automatisch das neueste GitHub-Release.
- Unter „Über das Programm“ kann manuell nach Updates gesucht werden.
- Für automatische EXE-Installation muss ein Release mit einer angehängten
  Windows-Datei „Game Center.exe“ veröffentlicht werden.
- Release-Tag muss eine Versionsnummer tragen, z. B. v0.8.0.

BUILD:
1. EXE_erstellen.bat auf Windows ausführen.
2. Die erzeugte EXE nach dem Testen als Asset an ein GitHub-Release anhängen.

WICHTIG:
Die Updateprüfung kann erst ein Update finden, wenn auf GitHub ein Release
mit höherer Versionsnummer und EXE-Datei veröffentlicht wurde.
Die Einstellungen bleiben im Ordner „Game Center“ neben der EXE gespeichert.
